## Lost Odyssey — Tradução PT-BR Feita com IA
CHATGPT 🤣🤣🤣🤣 (Fez o trabalho de tradução e edição de imagens para pt-br)

Projeto independente de tradução de **Lost Odyssey para português brasileiro**, desenvolvido para o **LostOdysseyRecomp**.

A tradução abrange diálogos, legendas, menus, itens, equipamentos, habilidades e descrições. Também inclui adaptações gráficas da interface de batalha e correções de textos de interação e localização.

### Versão atual: V1 (Disco 01)

- Textos e interface gráfica reunidos no mod `pt-br`.
- Revisão de mais de 43 mil entradas.
- Validação dos arquivos JSON, códigos e parâmetros técnicos.
- Ajustes de termos e textos longos identificados durante os testes.

### Estado do projeto 

**Em revisão e testes.** Ainda existem pendências em textos de cenário e imagens dos tutoriais. A cobertura integral dos quatro discos e dos DLCs ainda precisa ser confirmada.

Projeto não oficial, sem vínculo com os detentores dos direitos de Lost Odyssey.

Instalação
1. Feche o LostOdysseyRecomp.
2. Baixe e extraia o arquivo LostOdyssey_PTBR_V150_Unificado.zip.
3. Copie a pasta pt-br para a pasta mods do LostOdysseyRecomp.
